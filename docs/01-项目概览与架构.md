# ABC English 项目概览与架构

## 1. 项目目标

ABC English 是一个按 CEFR A1–C2 组织内容的英语词汇学习网站。当前公开项目负责线上浏览与管理能力，包括词汇分类、搜索、例句、字段遮罩、收藏夹、用户和管理员页面、主题设置及 PWA。

数据采集、批量 TTS、对象存储同步、数据库维护和备份由私有配套项目完成。线上请求不执行这些耗时任务，避免数据生产流程影响用户访问。

## 2. 运行架构

```text
浏览器（React + React Router）
        │ 同域 /api，Cookie 随请求发送
        ▼
Vercel 静态站点 + 单个 Node.js Function
        │ Express 路由 / 中间件 / 服务
        ▼
Prisma Client
        │ POSTGRES_PRISMA_URL（池化连接）
        ▼
Neon Postgres
```

前端和 API 使用同一域名，因此不需要向浏览器公开数据库连接信息，也不需要额外配置跨域 API。认证 Cookie 为 `HttpOnly`，前端只能通过 `/api/auth/me` 获取公开用户信息。

## 3. 目录职责

| 路径                     | 职责                                                         |
| ------------------------ | ------------------------------------------------------------ |
| `api/index.js`           | Vercel Node.js Function 入口，导出 Express 应用              |
| `server/src/app.js`      | 组装中间件、路由、错误处理和静态站点 fallback                |
| `server/src/routes/`     | HTTP 参数验证、权限边界和响应结构                            |
| `server/src/services/`   | 认证、词汇查询、日志等业务和数据访问逻辑                     |
| `server/src/middleware/` | 登录识别、管理员权限、安全头、来源检查、请求日志             |
| `prisma/postgres/`       | Prisma 模型及版本化 SQL 迁移                                 |
| `web/src/features/`      | 按 auth、vocabulary、favorites、admin、settings 划分页面功能 |
| `web/src/https/`         | Axios 基础服务及按业务域划分的具名请求方法                   |
| `web/src/services/`      | PWA、通知等不涉及 HTTP URL 的前端公共能力                    |
| `web/public/`            | Manifest、Service Worker 和公开图标                          |
| `vercel.json`            | Vercel 构建目录、Function 限制和路由重写                     |

## 4. 请求链路

以收藏词汇为例：

1. `WordCard.jsx` 调用 `web/src/https/requests/collections.js` 中的具名收藏方法。
2. 业务请求方法通过 `web/src/https/index.js` 的统一 Axios 实例发送请求。
3. Vercel 把 `/api/collections/...` 重写到 `api/index.js`。
4. `server/src/app.js` 依次执行安全头、请求日志、JSON、Cookie、同源检查和可选认证。
5. `collectionRoutes.js` 使用 `requireAuth` 确认用户身份，并校验参数。
6. `postgresVocabularyService.js` 与 Prisma Client 查询 Neon Postgres。
7. 路由只返回当前用户有权访问的数据。

新增功能时应维持这条边界：页面不直接访问数据库；路由负责输入和权限；服务负责可复用业务及数据查询。

## 5. 模块关联约定

- `vocabularyService.js` 是词汇数据门面。路由应依赖门面，不直接绑定具体 PostgreSQL 实现。
- `AuthContext.jsx` 只保存公开用户和认证加载状态；密码和原始登录令牌不得进入 React 状态或 Local Storage。
- `web/src/https/index.js` 是唯一 Axios 基础入口。组件只能调用 `https/requests/` 中的具名方法，不能直接写 URL、`fetch` 或 `axios`。
- `errorLogService.js` 负责结构化日志和持久化错误。业务代码不应记录请求体、Cookie 或令牌。
- Prisma Schema 是公开站点和私有数据工具共享的数据契约。字段变更需要同步迁移和两边的 Prisma Client。

## 6. 设计边界

当前规模不需要微服务、复杂全局状态库或拆分多个数据库。优先保持模块职责清晰、接口可测试和数据库查询次数可控。任何架构升级都应由真实流量、查询计划或发布冲突驱动。
