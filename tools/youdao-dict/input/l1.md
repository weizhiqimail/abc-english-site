# 词汇\-词根1【\-cess、\-ceed、\-cede、\-gress、\-gred、\-grad】

# -cess、-ceed、-cede、-gress、-gred、-grad

- **都可以表示“走”的意思，也就是“to go”**
- **s t d 三个字母可以互相转换**
  - conclu**d**e conclu**s**ion
    - conclude：断定，推断出；达成，做成，完成
      - In order to conclude the business, I hope you’ll meet me halfway. 为了做成这单生意，我希望双方都能各让一步。
    - conclusion：结论，推论；结局，结尾；
      - She considers that it is too early to form a definite conclusion. 她认为现在下确切的结论还为时过早。
  - deci**d**e deci**s**ion
  - conver**t** conver**s**ion
  - permi**t** permi**s**sion
  - admi**t** admi**s**sion
- **eat → -es / -ed**
  - obese：/oʊˈbiːs/，肥胖的，臃肿的
  - edible：/ˈedəb(ə)l/，可食用的；食物
    - edible oil：食用油
    - edible fungus：食用菌，木耳
      - fungus：/ˈfʌŋɡəs/，真菌，真菌类植物，霉菌
- processor：处理器
  - image processor：图片处理器
    - **-or / -ar / -er / -ur：**
      - 名词，表示……人，……机、器；
        - tractor：拖拉机，牵引机；
- procession：队伍，行列；一列，一排；列队行进
  - pro（向前）+cess（走）+ion（名词），一群人向前走
- graduate：v. 毕业；n. 本科毕业生
  - grad（走）+u（链接符号）+ate（名词或名词后追），要走（要离开学校）
  - **词根 + u/ul/o/ol（链接符号）+后缀**
    - stimulate：v. 促进，刺激；激发，激励
      - stim（刺）+u+late
  - **-ate / -ite / -ute：**
    - 用作动词后缀，表示“使……”；
    - 做形容词后缀
    - 少数做名词后缀；此时表示人或物。
  - undergraduate：本科在读生，本科肄业
- ingredient：n. （食品）原料、要素、组成部分
  - in（进入）+gredi（=go 走）+ent（名词后缀），走进去（构成新事物）的材料
- ag**gress**ive：adj. 侵略性的，激进的
  - ag（加强语气）+gress（=go）+ive（形容词后缀）：强行走进去
  - aggressive behavior：侵略性行为
  - **aff- / add- / acc-：类似于这样的结构开头的词汇，统称为 axx 结构。**
    - 这里的 **ax1** 表示前缀，从**x2**开始，就是词根部分。
    - aggress：侵略
  - ad- / a-：前缀，1️⃣ 表示**to，去**；2️⃣表示**加强语气**，类似于中文的“啊”
- aggression：n. 侵略，激进
- ag**gress**：v. 侵略
  - ag：表示加强。gress：表示走进去。合起来就是：强行走进去，就是侵略。
- progress：v/n. （人的事业）进步，前进
  - make rapid progress：取得了快速的进步
- process：n. 过程、进程；v. 处理，加工。
  - **pro-：forward，向前，前进地**
  - data processing：数据处理
  - information processing：信息处理
- proceed：v. （活动、事件、诉讼等）前进，继续进行；继续
  - proceed with：继续进行、着手推进……
  - proceed to：前往……，进入到……。
- proceeding：n. 诉讼，议程
  - legal proceeding：法律诉讼
- procedure：n. 程度，步骤
  - surgical procedure：手术程序
  - legal procedure：法律程序
- precede：v. 领先于，优于
  - pro（提前，前面）+cede：走在前面
  - **pro-：表示向前（动态）**
  - **pre-：表示提前（静态）**
- precedent：n.先例，前例；adj. 先前的
  - president：总统、主席
  - **-ent / -ant：名词后缀表示“人或物”。形容词后缀，表示“……的”**
- unprededented：adj. 史无前例的，空前的
- preced**ence**：n. 优先，居先
  - **-ance / -ence / -ancy / -ency：名词后缀，不表示某种含义**
  - priority：n. 优先权，优先
  - prior：adj. 优先的，领先的
  - prior + ity（名词后缀）：优先，居先
  - give precedence / give priority to sth：优先考虑某事
- access：v/n. 接近，进入；使用，获取
  - **ac（加强语气）+ cess（走）：走过去**
  - access email：查收邮件
  - have access to：使用……，查收……
- accessible：adj. （人）可接近的，（物）可使用的，（物）可获得的
  - accessible capital：可用资金
- accessory：n. 附件，配件，从犯
  - **ac（加强语气）+cess（走）+ory（名词后缀）：走进去，加入的东西**
- recession：n. 经济衰退；凹处；后退，不景气
  - re（回）+cess（走）+ion（名词后缀）：经济往回后
  - **re-：**
    - **1️⃣相反。resent：反感**
    - **2️⃣返回，回来。return：返回。**
    - **3️⃣反复，又，再；加强。repeat：又一次，再一次。**
  - recede：v. 后退，衰退
- excess：n. 无节制，过度，过量；超出，超额；adj. 过度的，过量的
  - **e- / ex- / es-：1️⃣向外；2️⃣出去，超出**
  - global excess demand：全球过度需求
  - excess weight：过重
- excessive：adj. 过分的，过多的，极度的
  - **-ive：1️⃣adj 后缀，表示大、多。2️⃣n 后缀，表示人或物。**
- exceed：vt. 胜过，超过
  - excess：n.
  - exceed：v.
  - process：n.
  - proceed：v.
- exceedingly：adv. 极其，非常；极度的
  - exceedingly polite forms：极其有礼貌的形式
- cease：v/n. 停止，终了
  - ceas（=cess：走，引申出走到尽头）：走到尽头
  - cease fire：停火
